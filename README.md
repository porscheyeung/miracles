# 科學做得到？神蹟又是甚麼？（V2）

小一至小六基督教兒童講道（約 30 分鐘）的全螢幕互動網站，可取代 PowerPoint。純前端單檔 `index.html`，無外部依賴；`v1.html` 為使用者提供的第一版原檔。

公開網站：https://porscheyeung.github.io/miracles/

## 流程（15 個場景，約 30 分鐘）
封面 → 奇妙的事 → 磁石實驗 → **碘水＋維他命 C 現場實驗** → 再做一次（實驗簿）→ 看起來神奇就是神蹟？ → 迦拿小鎮 → 酒用完了 → 六口石缸 → 水變酒揭曉 → 科學實驗 ≠ 神蹟 → 神蹟指向耶穌（約 2:11、20:30–31）→ 天父的愛 → 全班挑戰 → 總結與禱告

## 操作
- → / 空白鍵 / Enter：下一步（頁內動畫會逐步推進，完成後才換頁）；← 上一頁
- 碘水頁：1、2、3 對應三個步驟，R 重做
- 問答頁：A、B、C 選答案
- N 提示、M 場景目錄、F 全螢幕、B 或 . 黑屏、P 開講者視窗
- 講者視窗（`?presenter=1`）：計時、講稿、下一步預告；與投影視窗用 BroadcastChannel 同步（同一瀏覽器、同一網站開啟）
- `?s=9` 直接從第 9 頁開始

## 內容原則
- 不把耶穌描繪成魔術，不編造經文沒有交代的變化過程；水變酒只呈現經文記載的結果。
- 科學暫時解釋不到 ≠ 已證明是神蹟；沒有看見神蹟 ≠ 天父不愛我們。
- 實驗由成人操作，所有實驗液體不可飲用。
